# Food photo sources

The photographs in this folder are used as inputs for the ViT Grad-CAM demo.

- `pizza.jpg`: [Neapolitan pizza](https://commons.wikimedia.org/wiki/File:Neapolitan_pizza.jpg), Stevemconst61, public domain.
- `cheeseburger.jpg`: [Cheeseburger](https://commons.wikimedia.org/wiki/File:Cheeseburger.jpg), Renee Comet / US National Cancer Institute, public domain.
- `hot_dog.jpg`: [NCI Visuals Food Hot Dog](https://commons.wikimedia.org/wiki/File:NCI_Visuals_Food_Hot_Dog.jpg), Renee Comet / US National Cancer Institute, public domain.
- `ice_cream.jpg`: [Ice cream cone](https://commons.wikimedia.org/wiki/File:Ice_cream_cone.jpg), D. Sharon Pruitt, [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/).

The demo center-crops each source photograph to the 224 x 224 ViT input.
